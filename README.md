      <p><i>3.839 tabelas. 44.309 campos. Zero paciência para procurar na mão.</i></p>
      <p>
        <b>O problema —</b> consultar a estrutura de um banco corporativo era um processo manual e lento no dia a dia de sustentação.<br><br>
        <b>A solução —</b> aplicação web que indexa o dicionário de dados inteiro: busca em tempo real por tabela ou campo, filtro dentro de cada tabela e destaque visual de chaves primárias — inclusive as compostas. Distribuição empacotada em ZIP, com inicialização em um clique.

      <h3><a href="https://github.com/SamuelDeMarco-Dev/SitedePrevisaodoTempo">🌤️ ClimaTempo</a></h3>
      <p><i>API externa muda. Sua aplicação não pode ir junto.</i></p>
      <p>
        <b>O problema —</b> consumir uma API de terceiros sem acoplar a interface ao formato de resposta dela — trocar de fornecedor não pode quebrar a aplicação inteira.<br><br>
